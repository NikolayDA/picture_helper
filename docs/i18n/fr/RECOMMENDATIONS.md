La contre-vérification a mis au jour trois erreurs de la première analyse ; toutes trois sont vérifiées dans le code :

- 🟠 **README.md reste pertinent pour le candidat**, `docs/i18n/**` seulement en partie. `pyproject.toml:15` définit `readme = "README.md"` (métadonnée de paquet). Les CHANGELOG, licences et manuels traduits sont pertinents ; les cinq `RECOMMENDATIONS.md` sont des entrées **release-neutral** strictement justifiées dans `release/path-policy.json`. Les chemins inconnus restent pertinents et bloquants (#743).
- 🟠 **`tests/test_release_gate.py` existe déjà** — plus de 20 invariants du workflow, dont le test de régression de l'interblocage #709 issu de #715. Le #747 initial aurait dupliqué l'existant ; il vise désormais le nouveau contrat de #742/#744.

De même, #731 distingue à juste titre les causes ClamAV (Linux : verrou sur `/var/log/clamav/freshclam.log` ; macOS : magasin X509) — le commentaire global de `release-linux.yml:413` est à corriger.
